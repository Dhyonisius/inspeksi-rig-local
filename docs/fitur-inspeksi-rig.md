# Inspeksi rig — fitur aktif

Aplikasi difokuskan pada pemeriksaan foto dengan model visi lokal, kurasi Protect, peninjauan label dan kotak bahaya, contoh terverifikasi, riwayat pemeriksaan, pengelolaan dataset rig, pembagian kelompok PDF, pelatihan/evaluasi detektor rig, dan konfigurasi.

Panduan label internet, bantuan SH17/APD, dataset publik, chat foto, inspeksi langsung, dan menu Performa dilepas sesuai permintaan pengguna. Kamera untuk mengambil satu foto tetap tersedia pada pemeriksaan foto. Model Gemma tetap digunakan untuk deskripsi dan indikasi visual.

Foto, label, hasil tinjauan dan riwayat database dipertahankan. Tabel lama disimpan untuk menjaga data dan kompatibilitas; endpoint fitur yang dilepas tidak aktif. Kode sebelum penyederhanaan disimpan dalam outputs/backups/sebelum-penyederhanaan-rig-20261013-154221.
